# Glossaire

| Mot | Sens dans Hexis |
|---|---|
| **RPE** | Effort d'une série de 1 à 10 (10 = max). Saisi par la jauge. |
| **RIR** | Reps en réserve (combien d'autres répétitions étaient possibles). Stocké : `rir = 10 − rpe`. |
| **e1RM** | Charge maximale estimée sur 1 répétition, formule d'Epley : `poids × (1 + reps / 30)`. Sert à comparer des séries de reps différentes. |
| **Déload** | Semaine allégée : mêmes charges, moitié des séries. Dernière semaine du cycle de 6, ou avancée si fatigue. |
| **Cycle** | 6 semaines : reprise, 4 semaines de progression, déload. |
| **Superset** | Deux exos (ou plus) enchaînés sans repos entre eux ; une barre de couleur les relie. |
| **Double progression** | On monte d'abord les reps jusqu'en haut de la fourchette, puis la charge. |
| **Plateau** | ≥ 3 séances sans meilleur e1RM pour un exo. L'app réagit par une échelle (+1 pas, +1 série, −5 % de charge, fourchette décalée). |
| **Baisse** | Performance à −7 % du meilleur récent sur 2 séances à effort égal. |
| **Pas de machine** | Plus petit incrément de charge de la machine ; les charges sont arrondies à ce pas. |
| **Fourchette** | Intervalle de reps visé (ex. 8–10). |
| **Fatigué / Gêne** | Seuls ressentis : Fatigué (par séance : on ne pousse rien) ; Gêne (par exo : alimente la réhab). |
| **Réhab** | Blocs de renforcement du mollet par phases de 4 semaines, 12 semaines au total. |
| **Reprise** | Après 8 jours sans séance, charges −5 % ; après 15 jours, −10 %. |
| **Échauffement** | Séries `W` calculées en % du poids de travail. |
| **Cycle d'alimentation** | Semaine de courses lundi → dimanche, qui bascule le vendredi 18 h. |
| **Batch** | Cuisine du dimanche pour la semaine. |
| **Semaine libre** | Vacances ou semaine sans suivi : le stock et le plan ne bougent pas. |
| **Live Activity** | Décompte du repos sur l'écran verrouillé et la Dynamic Island. |
